Build your metadata catalog

Paste Civitai model links (one per line), optionally add your Civitai API token, and every entry is stored locally: images, trigger words, versions, files and hashes.

Nothing is downloaded from Civitai except metadata JSON — previews stream straight from the Civitai CDN. No ComfyUI installation is required.

Add Civitai links

One link per line. Model pages, version links and bare numeric ids all work. Existing entries are updated in place.

A token is needed for mature or early-access models and helps with rate limits. Get one at civitai.com → Account settings → API keys.
